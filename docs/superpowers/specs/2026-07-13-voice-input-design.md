# 语音输入功能设计

> 日期：2026-07-13 | 状态：设计完成，待用户审阅

## 概述

为 Jarvis 助手新增语音输入能力，面向老人和不识字的儿童，让他们通过说话代替打字来使用 AI 助手。

## 范围

**纯前端改动**，后端零修改。语音识别结果复用现有 `handleSend()` 流程，所有现有功能（流式聊天、RAG、思考动画、终止回答等）保持不变。

---

## 方案

- **语音引擎**：浏览器内置 Web Speech API（`SpeechRecognition`），语言 `zh-CN`
- **交互方式**：双模式切换 — 文字模式 ⇄ 语音模式
- **发送方式**：语音模式下按住中间区域说话，松手自动发送
- **新增文件**：`frontend/voice.js`
- **修改文件**：`frontend/index.html`、`frontend/script.js`、`frontend/style.css`

---

## 架构

```
文字模式                       语音模式
┌─────────┐   点🎤    ┌─────────────────┐
│ textarea│ ───────→ │  按住说话区域     │
│  🎤 ＋  │          │    ⌨   ＋       │
└─────────┘          └─────────────────┘
     ↑                      │
     └──────────────────────┘
               点⌨

voice.js (Web Speech API 封装)
     │
     ├── onStart → Vue 进入"聆听中"状态
     ├── onResult(中间) → 实时文字展示
     ├── onResult(最终) → 填入 → 调用 handleSend()
     ├── onError → 错误状态 + 提示音
     └── onEnd → 恢复语音模式空闲
```

语音模块 `voice.js` 与 Vue 无关，通过回调通信，可独立测试。

---

## voice.js 模块

```js
class VoiceInput {
  constructor({ onStart, onInterim, onResult, onError, onEnd })

  start()      // 检查权限 → 创建 SpeechRecognition → 开始
  stop()       // 停止 → 取最终结果
  abort()      // 取消不留结果
  static isSupported  // !!window.SpeechRecognition
}
```

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 语言 | `zh-CN` | 中文识别 |
| interimResults | `true` | 实时显示中间结果 |
| continuous | `true` | 按住期间持续收音 |

## UI 状态机

### 三种按钮布局

| 按钮 | 文字模式 | 语音模式 |
|------|----------|----------|
| 左侧 | （无，textarea 占满） | 按住说话区域 |
| 中间 | 🎤 — 切换到语音模式 | ⌨ — 切回文字模式 |
| 右侧 | ＋ — 附件上传 | 同左 |

### 语音模式四态

```
空闲 idle        聆听中 listening      识别中 processing      错误 error
┌────────┐      ┌────────┐           ┌────────┐           ┌────────┐
│ 按住   │ 按下  │ 🔴 脉冲 │  松手/超时  │ ⏳ 旋转 │  失败     │ ⚠️ 闪烁 │
│ 说话   │ ───→ │ + 波纹 │ ────────→ │ 识别中  │ ────────→ │ 2.5s后  │
└────────┘      └────────┘           └────────┘           └────────┘
                     │                    │                    │
                     │ 3秒无声             │ 成功                │ 自动恢复
                     ↓                    ↓                    ↓
                  识别失败              自动发送             回到空闲
```

### 视觉效果

1. **空闲** — 居中显示 "按住说话"，灰色文字，等待用户操作
2. **聆听中** — 区域背景变红色调，外圈扩散波纹动画，实时识别文字浮动显示
3. **识别中** — 区域变蓝紫色调，旋转加载动画，文字冻结
4. **错误** — 橙黄色闪烁，2.5 秒后回到空闲

### 提示音

用 `AudioContext` 动态生成，无需音频文件：

| 事件 | 提示音 |
|------|--------|
| 开始录音 | 1kHz 短升调 |
| 识别失败/无声 | 300Hz 低音短鸣 |
| 识别成功 | 800→1200Hz 双音节 |

## 错误处理

| 场景 | 表现 | 降级策略 |
|------|------|---------|
| 浏览器不支持 | 不显示 🎤 按钮 | 仅保留文字输入，功能完整 |
| 麦克风权限被拒 | 语音区域显示 "无权限"，2s 后自动切回文字模式 | 回退到文字 |
| 识别结果为空 | 短振动 + 低音 beep | 保持在语音模式，可重试 |
| 连续 3 秒无声 | 同上 | 保持在语音模式 |
| 识别接口不可用 | 显示 "网络不可用" | 切回文字模式 |
| 按住期间点⌨ | abort 识别后切换 | 不留残留状态 |
| 流式回答中按语音 | 阻止 | 等回答完成 |
| 未登录 | 语音按钮置灰 | 禁用 |

## 附件上传（附带）
